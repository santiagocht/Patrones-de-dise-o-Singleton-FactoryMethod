# Nómina · Patrones creacionales — Programación I

Universidad Libre · Ingeniería de Sistemas · IV Semestre

Cada carpeta compila y funciona por sí sola. Los cambios de cada paso están marcados con comentarios 



| Carpeta | Qué cambia |

| `inicio` | La nómina actual, con los tres síntomas |
| `singleton` | Una sola `ConfiguracionNomina` para todo el sistema |
| `factory` | `FabricaEmpleados` crea empleados desde una línea de texto (entra `Contratista`) |
| `builder` | `ReciboNomina` se arma con `ReciboNomina.Builder` |
| `solucion` | Solución del reto
